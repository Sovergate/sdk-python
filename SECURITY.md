# Security policy

This SDK runs inside your infrastructure and sees prompts before PII is
scrubbed, so we take reports seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Instead, report it privately through
GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability**.

If you cannot use GitHub, email **hello@sovergate.com** with the subject
"Security report".

We aim to acknowledge reports within 3 business days and will keep you updated
until the issue is resolved.

## Supported versions

The SDK is in early access. Security fixes are released on the latest version
only.
